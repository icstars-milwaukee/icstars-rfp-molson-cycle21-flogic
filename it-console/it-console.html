    Data packs

    Locks data files for one or more groups. Only people in those groups can open the .flogic file it makes. Anyone can still see which groups it's for, and the file's name. Every pack is signed with IT's signing key, so nobody else can make or change one.

    Export starts as the strictest rule of the file's groups: if one group can't export, nobody exports that file. You can tick a group back on. The app still checks each person's own level and group.

    Signing key

    Every key file is signed with IT's signing key. It lives inside the keyring, locked with the IT passphrase. The app carries the public half in DIRECTORY/it-signerI.js (the "trust file"), and refuses key files signed by any other key.
