# SCANME

The short, read-this-first documents for the agents (and people) working on Flogic. If a file is here, it is current.

| File | What it is | For |
|---|---|---|
| `README.md` | This page | everyone |
| `SWEEP-CONTINUE-v0.1.0.md` | The rest of the desktop speed sweep (`handoff/desktop-sweep-plan.md`): nine jobs Fernando's agent didn't get to | DJ's agent |

Returns go in `SCANME/returns/`. The file name is the task's name with the date added
(`SWEEP-CONTINUE-v0.1.0-2026-11-17.md`). Old returns stay; a new one never overwrites an old one.

Earlier SCANME files (the SSO briefs, audits and questions) are in git history, up to commit `47e96e4`.
